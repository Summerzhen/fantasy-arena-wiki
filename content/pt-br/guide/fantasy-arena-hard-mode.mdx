## Fantasy Arena Hard Mode

Hard Mode e para jogadores que ja tem uma build estavel no normal. Antes de entrar, confira codes, classe, wand e traits. Se um desses sistemas estiver fraco, Hard Mode transforma esse ponto fraco em derrota rapida.

## Checklist Antes do Hard Mode

| Requisito | O que revisar |
|-----------|---------------|
| Codes | Resgate [Fantasy Arena Codes](/pt-br/codes/fantasy-arena-codes) antes de gastar. |
| Classe | Use uma classe com papel claro em [Classes](/pt-br/classes). |
| Wand | Equipe uma wand com dano consistente em [Wands](/pt-br/wands). |
| Traits | Priorize dano, uptime ou sobrevivencia em [Traits](/pt-br/traits). |
| Build | Compare o setup em [Builds](/pt-br/builds). |

## Quando Entrar

Entre no Hard Mode quando conseguir limpar waves normais sem depender de sorte. Se perde por falta de dano, melhore wand ou traits. Se perde por pressao, adicione sobrevivencia antes de continuar.

## Erros Comuns

- Entrar apenas porque Hard Mode tem recompensas melhores.
- Ignorar codes antes de gastar recursos.
- Usar uma build de farming sem defesa.
- Trocar classe sem ajustar wand e traits.

## FAQ

### Hard Mode vale a pena?

Se sua build ja e estavel, sim. Se ainda falha no normal, melhore classe, wand e traits primeiro.

### Que build usar no Hard Mode?

Comece com [Fantasy Arena Best Builds](/pt-br/builds/fantasy-arena-best-builds) e ajuste conforme o problema: dano, sobrevivencia ou boss pressure.
