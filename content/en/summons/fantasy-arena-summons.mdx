## What Are Summons in Fantasy Arena?

Summons are a class-linked part of the Fantasy Arena build system. They belong alongside classes, wands, and traits rather than replacing any of them. A summon-focused setup should be evaluated by how its ability supports your goal: surviving Endless Waves, farming rewards, or handling a boss encounter.

The V1.2 update notes confirm **five new unique class summons**. The official update information does not provide a complete public list of names, damage values, cooldowns, or unlock requirements, so those details are marked **Unknown** here until they can be verified in-game or from an official source.

## How to Test a Summon Safely

1. Record the class and trait setup before changing anything.
2. Test the summon in a repeatable early wave so the comparison is fair.
3. Check whether it changes clear speed, survivability, boss pressure, or resource gain.
4. Repeat the test with the intended wand instead of judging the summon in isolation.
5. Note the exact unlock condition and ability text from the game UI.

For a complete comparison, keep separate notes for **Class**, **Ability**, **Effect**, **How to Unlock**, **Best Wand**, **Best Trait**, and **Best Build**. This keeps the page useful without inventing stats that have not been confirmed.

## Summons and Build Planning

The practical route through Fantasy Arena is:

**Class → Summon → Wand → Traits → Build → Endless Waves**

Start with the job you want the build to do. A high-wave build may value reliable control and survivability, while a farming build may value uptime and clear speed. Once the summon effect is verified, compare it with the [Fantasy Arena Builds](/en/builds), [Fantasy Arena Wands](/en/wands), and [Fantasy Arena Traits](/en/traits) pages.

## Frequently Asked Questions

### How many new summons were added in V1.2?

The V1.2 update notes confirm five new unique class summons.

### Are all five summon names confirmed?

Not from the public information currently available to this wiki. Names, effects, and unlock requirements should be added only after an in-game or official verification.

### Are summons separate from classes?

They are best treated as a separate build dimension linked to classes. A summon should be evaluated together with its class, wand, and traits.

### Where should I start with summons?

Start with the class that provides the summon, then test the summon with one wand and a small set of traits. Record results before assigning a tier ranking.
