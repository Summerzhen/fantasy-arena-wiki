## Fantasy Arena V1.4 Frost Event

Fantasy Arena V1.4 launched on **August 22, 2026**. The official Roblox game listing confirms a new Frost event, a limited-time Mythic class and scythe, wand stacking, a Mushroom map, and a new map quest.

## What V1.4 Added

| New feature | What is confirmed |
|-------------|-------------------|
| Frost event | A new limited-time event theme |
| Mythic class | A limited-time Mythic class is listed in the update notes |
| Scythe | A limited-time scythe is listed alongside the Mythic class |
| Wand stacking | The update adds a new wand-stacking mechanic |
| Mushroom map | A new map is available in the update |
| Map quest | A new quest is listed for the map |

The official listing confirms the features, but it does not publish every drop rate, unlock requirement, or stat. Treat specific costs and rewards as unverified until they are visible in-game.

## Where to Start

1. Open the Frost event in the live game and read its in-game objectives.
2. Check whether the Frost Crate or event reward path is available on your account.
3. Test wand stacking with a short run before changing a complete build.
4. Follow the Mushroom map quest markers and record the exact objective shown in your server.

Continue with the [Frost Crate Guide](/en/guide/fantasy-arena-frost-crate), [Scythe Guide](/en/guide/fantasy-arena-scythe), or [Wand Stacking Guide](/en/wands/fantasy-arena-wand-stacking).

No V1.4 Frost-specific code is confirmed in the current code evidence. Check the [Fantasy Arena Codes](/en/codes/fantasy-arena-codes) page for codes that are actually reported and verify each one in the lobby.
