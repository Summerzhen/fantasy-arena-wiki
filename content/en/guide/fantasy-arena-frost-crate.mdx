## Fantasy Arena Frost Crate

The Frost Crate is part of the new V1.4 Frost update focus, but the official Roblox listing does not publish its exact cost, drop table, or odds. Use the live event interface as the source of truth for those details.

## How to Check the Frost Crate

1. Launch the official [Fantasy Arena Roblox experience](https://www.roblox.com/games/73227142902215/Fantasy-Arena).
2. Enter the lobby and open the Frost event or crate interface.
3. Read the displayed cost and reward preview before spending resources.
4. Take a screenshot or note the result if the interface changes between servers.

Do not assume that a Frost Crate contains the Mythic class or Scythe unless the in-game reward preview says so. Those are confirmed update features, not a published drop-table guarantee.

## Frost Crate Farming Plan

Use a run you can clear consistently, save enough Burgers for your main progression, and test one crate opening before committing your entire reserve. Pair observations with the [Frost Event Guide](/en/guide/fantasy-arena-frost-event) and [Fantasy Arena Codes](/en/codes/fantasy-arena-codes).
