## What Is Wand Stacking?

Wand stacking is a new mechanic listed in Fantasy Arena V1.4. The official update confirms the feature but does not publish a universal stack limit, exact stat formula, or complete compatibility list.

## How to Test Wand Stacking

1. Start with one wand and record your normal wave-clear time.
2. Add the next wand through the live interface and note the displayed change.
3. Test the same class, traits, and wave range so the comparison is useful.
4. Check whether the effect changes damage, range, attack speed, cooldowns, or another displayed stat.
5. Stop if the setup costs more than the run can reasonably recover.

## Best Wands for Stacking

Until the live game publishes or demonstrates a stable formula, rank stacking candidates by compatibility and repeatable damage rather than rarity alone. A wand that is slightly weaker by itself may become valuable if its effect combines cleanly with your main wand.

| Test | Question |
|------|----------|
| Damage | Does the second wand increase actual wave-clear DPS? |
| Bosses | Does the effect remain useful against a single target? |
| Survival | Does stacking reduce the time you spend exposed? |
| Cost | Can the run recover the resources spent? |
| Class fit | Does the class amplify the stacked effect? |
