## Fantasy Arena Hard Mode

Hard Mode es para jugadores que ya tienen una build estable en normal. Antes de entrar, revisa tus codes, clase, wand y traits. Si uno de esos sistemas esta debil, Hard Mode convierte ese problema en una derrota rapida.

## Checklist Antes de Hard Mode

| Requisito | Que revisar |
|-----------|-------------|
| Codes | Reclama [Fantasy Arena Codes](/es/codes/fantasy-arena-codes) antes de gastar. |
| Clase | Usa una clase con rol claro desde [Classes](/es/classes). |
| Wand | Equipa una wand con dano consistente desde [Wands](/es/wands). |
| Traits | Prioriza dano, uptime o supervivencia en [Traits](/es/traits). |
| Build | Compara tu setup con [Builds](/es/builds). |

## Cuando Entrar

Entra a Hard Mode cuando puedas limpiar waves normales sin depender de suerte. Si pierdes por falta de dano, mejora wand o traits. Si pierdes por presion, agrega supervivencia antes de seguir.

## Errores Comunes

- Entrar solo porque Hard Mode da mejores recompensas.
- Ignorar codes antes de gastar recursos.
- Usar una build de farming sin defensa.
- Cambiar de clase sin ajustar wand y traits.

## FAQ

### Hard Mode vale la pena?

Si tu build ya es estable, si. Si aun fallas en normal, primero mejora clase, wand y traits.

### Que build usar en Hard Mode?

Empieza con [Fantasy Arena Best Builds](/es/builds/fantasy-arena-best-builds) y ajusta segun tu problema: dano, supervivencia o boss pressure.
